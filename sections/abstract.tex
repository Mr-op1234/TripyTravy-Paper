\begin{abstract}
TripyTravy lets agents prepare itineraries in a desktop Creator and send schedules and supporting assets to a mobile Viewer in a versioned \texttt{.tt} file. Every new beta export requires a passphrase. Both apps use a Dart codec with AES-256-GCM and Argon2id-based key derivation. The Viewer prompts for the passphrase at import. A newer revision can replace the saved schedule while keeping the traveler's checklist and completion status. We compared the workflow with Travefy and evaluated it with controlled fixtures and 93 host-side tests. With eight references to a single 1 MiB attachment, the package was 87.5\% smaller than one with eight distinct attachments of the same size. The protected importer rejected modified files and a wrong passphrase in host tests. We built the Windows and Android releases. File delivery on a phone and offline access after restart remain open tests.
\end{abstract}
